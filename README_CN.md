# RP2040-Zero STM8 SWIM 波形测试固件（独立测试版）

这个包是**第一阶段测试固件**：只用于让逻辑分析仪观察 GP2 上的 SWIM 激活波形，并通过 USB CDC 命令触发。它不是完整 STM8 烧录器，不会读取芯片、擦除 Flash 或写入 Flash。

## 固定引脚

- GP2：SWIM（开漏模拟：拉低时输出低电平，释放时切换为输入/高阻）
- GP4：NRST（开漏模拟）
- GND：逻辑分析仪和目标板共地
- 目标电源：本测试固件**不会控制或供应目标板电源**。请先单独确认 3.3V 供电方案。

## 安全注意事项

1. RP2040 GPIO **不耐受 5V**。目标 SWIM/NRST 电平必须限制在 3.3V 范围。
2. SWIM 需要外部上拉。建议先断开 STM8，仅在 GP2 与 3.3V 之间接约 4.7 kΩ 上拉电阻；连接目标芯片时，SWIM 串联 220–1000 Ω（可先用 470 Ω）。
3. 所有设备必须共地。先只接 RP2040 和逻辑分析仪，不要一开始就接目标芯片。
4. `entry-waveform` 期间 GP4 被拉低，波形结束后 GP4 释放为高阻。请确保目标板的 NRST 有有效上拉。
5. 本固件没有验证 STM8 同步应答，也不提供 Flash 操作。波形通过只是第一阶段，不代表芯片已能通信或烧录。

## 波形预期

在 GP2 上观察到：
1. 初始低电平约 16 µs；
2. 4 个 1 kHz 脉冲（周期约 1000 µs，约 50% 占空比）；
3. 4 个 2 kHz 脉冲（周期约 500 µs，约 50% 占空比）；
4. 结束后 GP2 释放为高阻，由外部上拉恢复高电平。

协议段理论时长约 6.021 ms（16 µs 起始低电平 + 5 µs 分隔高电平 + 4 ms 慢速脉冲组 + 2 ms 快速脉冲组），不包括 USB 命令处理时间。分隔高电平用于避免起始低电平与第一段 500 µs 低电平合并。由于普通 C GPIO 控制存在函数开销，实际脉冲宽度会有少量偏差；以逻辑分析仪实测为准。

## 编译

推荐用 GitHub Actions 在线编译（不需要在本地安装 Pico SDK）：

1. 将本 ZIP 解压。
2. 新建一个 GitHub 仓库，把解压后的文件上传到仓库根目录。
3. 打开仓库的 **Actions** 页面，允许 GitHub Actions。
4. 运行 `Build RP2040-Zero SWIM Test UF2` 工作流。
5. 在运行结果的 Artifacts 下载 `rp2040zero-swim-test-uf2`，解压得到 `.uf2`。

也可在已配置 Pico SDK 的环境中编译：

```bash
cmake -S firmware -B build -DPICO_BOARD=pico
cmake --build build -j
```

生成文件通常为 `build/rp2040zero_swim_test.uf2`。本项目以 RP2040-Zero 的 RP2040 芯片为目标；`PICO_BOARD=pico` 用于选择 RP2040 架构和 SDK 默认配置，程序使用的 GPIO 编号不依赖 Pico 板载 LED 引脚。

## 烧录与操作

1. 先不要连接 STM8。让逻辑分析仪 GND 与 RP2040 GND 相连，通道接 GP2；可再用另一个通道接 GP4。
2. RP2040-Zero 进入 BOOTSEL 模式，把 UF2 拷贝到弹出的盘符。
3. 正常重启后，用 USB 数据线连接电脑。
4. 打开串口终端，选择 RP2040 的 USB CDC 串口，波特率可设为 115200（USB CDC 实际不依赖波特率）。
5. 输入 `help` 并回车，查看命令。
6. 输入 `entry-waveform` 并回车，触发一次激活波形。
7. 逻辑分析仪建议采样率设为 10 MHz 或更高，捕获时长约 10 ms。

常用命令：

- `help`：帮助
- `status`：显示引脚和测试状态
- `entry-waveform`：发送一次波形
- `repeat 5`：连续发送 5 次，每次之间间隔 1 秒
- `release`：释放 GP2/GP4 为高阻
- `quit`：退出当前命令行提示（设备固件仍运行）

## 如果仍然只有尖峰

- 确认逻辑分析仪地线接到了 RP2040 GND。
- 确认通道确实接 GP2，而不是 GP2 以外的焊盘。
- 确认 GP2 到 3.3V 有外部上拉；没有上拉时，“释放”可能一直被读成低电平或浮动。
- 先断开 STM8，排除目标板把 SWIM 拉住或电平冲突。
- 若逻辑分析仪看到的数字波形正常，但示波器只有尖峰，检查示波器探头接地、探头衰减、耦合方式和测量点。
- 如果 GP2 仍然没有平台，请把逻辑分析仪截图（包含时间刻度）发来；不要进入 Flash 写入测试。
